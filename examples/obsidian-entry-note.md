# Third Brain V7 Home

Use this as a lightweight Obsidian entry note named `Third Brain V7 Home.md`.

## Today

- Daily loop: ask your agent to run `daily-okr`.
- New source: ask your agent to run `wiki-ingest`.
- End of session: ask your agent to run `session-learn`.
- Before shipping: ask your agent to run `verify-before-claim`.

## Fast Prompts

```text
Run daily-okr in compact mode and update today's note.
```

```text
Use wiki-ingest on this source and connect it to existing concepts.
```

```text
Extract what we learned this session and save reusable patterns to my wiki.
```

## Navigation

- `SOURCES_DIR` — immutable source notes
- `CONCEPTS_DIR` — reusable ideas and frameworks
- `ENTITIES_DIR` — people, companies, products, projects
- `OUTPUTS_DIR` — briefs, reports, decisions, reusable artifacts
- `MAPS_DIR` — maps of content
- `SYSTEM_DIR` — logs, templates, lint reports, and `system/config.md`

## Weekly Maintenance

- Run `wiki-lint`.
- Review stale notes.
- Merge duplicate concepts.
- Update one map of content.
