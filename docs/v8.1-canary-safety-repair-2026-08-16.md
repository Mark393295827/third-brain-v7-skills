## Additional release controls

- Every commit writes and immediately revalidates an exact, five-minute approval receipt plus durable commit intent before mutation.
- Transaction preimages are rechecked immediately before replacement.
- Rollback uses postimage compare-and-set and preserves later human/sync edits.
- Rollback metadata is exact-set checked; a new target cannot be restored from a forged backup.
- An all-written crash resumes only while its approval and intent remain valid.
- Freshness derives from `valid_as_of`, rejects future/mismatched review dates, and scans map/system dashboard surfaces.
- Concepts require three unique resolvable anchors to the declared source; ambiguous stem-only links fail.
- Source/concept frontmatter and typed Worker IPC execute the declared JSON-Schema subset at Governance boundaries.
- Queue suppression validates terminal receipt identity, contract, vault, mode, input hash, non-empty writes, and immutable source state instead of trusting file existence.
- CLI termination semantics return non-zero for every blocked/evidence/verification/progress/budget stop, preventing a scheduler from treating an incomplete run as success.
- Clipping ingestion is terminal only at `ARCHIVED`; archive repair is checkpoint-bound, idempotent, and never replays canonical knowledge writes.
