# V8.1 Codex Agentic OS Command Centre

The command centre is a read-only browser surface backed by a local Codex host. Codex is the primary host/kernel for this repository; Claude Code, Gemini, Cursor, and Windsurf are compatibility adapters.

## Start the host

From the repository root, choose an operator-owned state directory explicitly:

```bash
python tools/agentic_os_server.py --state-root .agentic-os-state
```

Open <http://127.0.0.1:8765/>. The host binds localhost by default. `/api/snapshot` is generated by the T02 runtime and includes repository/Vault evidence, registry hashes, debt/freshness and latest-run data when a Vault is configured. A missing Vault is `PARTIAL`; missing data is shown as `—`, never as a fabricated zero.

The browser may submit only an action id from the registry. It cannot submit an argv, path, shell fragment, environment variable, or verifier. `HOST_REQUIRED` and `UNAVAILABLE` actions are disabled. HTTP 2xx, timeout, model text, or UI animation is not success: only a terminal receipt with verifier `PASS` is success.

## Package and readiness

```bash
python tools/package_agentic_os.py --probe
python tools/package_agentic_os.py --output dist/third-brain-agentic-os-v8.1.zip
python tools/package_agentic_os.py --verify dist/third-brain-agentic-os-v8.1.zip
```

The allowlisted bundle contains the command centre, T02 runtime/registry, V8.1 system support, docs, and installers. It excludes credentials, plugins, host schedulers, Vault contents, source bodies, and run state. Manifest SHA-256 verification is required.

Installers support `bundle` / `agentic-os` and write to `$THIRD_BRAIN_BUNDLE_DIR` (or `%THIRD_BRAIN_BUNDLE_DIR%`). Automatic installation prefers Codex at `<install-home>/.agents/skills`; other harnesses require an explicit compatibility target.

## Optional Codex Vault navigation sync

This is a separate, explicit lane. It is read-only by default and never touches `.claude/`, `settings.local.json`, or plugin files:

```bash
python tools/sync_vault_codex.py --vault-root /path/to/vault --install-home "$HOME" --state-root .agentic-os-state
python tools/sync_vault_codex.py --vault-root /path/to/vault --install-home "$HOME" --state-root .agentic-os-state --approve
```

Approval writes only Vault-root `AGENTS.md` from the reviewed V8.1 template and the manifest-managed global Codex skills directory. It records preimages, uses an exact-target allowlist, creates a backup, writes atomically, performs read-after-write checks, and emits a receipt below the supplied state root. A CAS mismatch blocks the write.

Schedulers, credentials, connectors, billing, headless model invocation, external publication, Obsidian plugin installation, live Vault commit, and external metrics remain host-dependent boundaries. The canonical V8.1 flow remains Stage → Author → Graph Plan → Govern → approved Commit/Postcheck.
