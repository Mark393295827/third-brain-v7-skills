# Third Brain V7.2 / V5.0 Tag Taxonomy Reference

This reference defines the official, hierarchical tag taxonomy used across all notes in the Obsidian Vault.

---

## 1. Domain Tags (`#domain/...`)

Used on concept notes and domain MOCs to identify primary knowledge domains:

- `#domain/ai-engineering` — Agentic AI, Loop Engineering, Harness, Claude Code, SDLC, Graph Engineering, MCP
- `#domain/ai-economics` — Tokenomics, CapEx, Compute, Data Centers, GPUs, Cloud Infrastructure, Hardware
- `#domain/ai-science` — AGI, Interpretability, World Models, RL, Distillation, Pre-Training, Test-Time
- `#domain/behavioral-econ` — Kahneman, Nudges, Decision Frameworks, Cognitive Friction, Mental Models, Bias
- `#domain/business-strategy` — Moats, 7 Powers, Competitive Strategy, Pricing, Disruption, Operating Leverage
- `#domain/entrepreneurship` — Startups, PMF, GTM, Founder Operations, Company Building, Scaling
- `#domain/general-concepts` — Multidisciplinary core concepts, general mental models
- `#domain/geopolitics-energy` — Semiconductors, Export Controls, Nuclear/SMR, Power Grid, Critical Minerals
- `#domain/identity-culture` — Philosophy, Sociology, Education, Human Relationships, Storytelling, Civics
- `#domain/investing-macro` — Fed, FOMC, Bonds, Housing, Inflation, Interest Rates, Liquidity, Debt Cycles
- `#domain/investing-quant` — Quantitative Trading, Factor Investing, Smart Beta, Signal-to-Noise, Portfolio Risk
- `#domain/investing-vc` — VC Frameworks, Private Equity, Term Sheets, Deal Sourcing, Valuation, Pitching
- `#domain/knowledge-systems` — PARA, Second Brain, LLM Wiki, Obsidian, STOW/CODE Pipelines, Knowledge Ops

---

## 2. Note Type Tags (`#type/...`)

- `#type/concept` — Concept, framework, method, or theory notes
- `#type/entity` — Entity notes (people, companies, funds, products, orgs)
- `#type/source` — Immutable source clipping notes
- `#type/sop` — Standard Operating Procedure notes
- `#type/map` — Maps of Content and navigation indexes
- `#type/output` — Reusable briefs, evaluations, and cognitive compiles

---

## 3. Entity Category Tags (`#entity/...`)

- `#entity/people` — Individuals, founders, researchers, investors
- `#entity/companies` — Tech companies, startups, enterprises
- `#entity/funds-investors` — VC funds, PE firms, hedge funds
- `#entity/products` — Developer tools, AI models, platforms
- `#entity/orgs` — Universities, government bodies, research institutes

---

## 4. Evidence & Status Tags

- `#evidence/primary` — Derived directly from primary literature or verified code
- `#evidence/single-source` — Unverified single-source evidence (requires caution)
- `#status/active` — Active, production-ready knowledge note
- `#status/seed` — Draft or initial seed note needing expansion
